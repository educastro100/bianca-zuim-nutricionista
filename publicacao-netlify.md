PUBLICACAO NO NETLIFY
=====================

Status atual
------------
O site ja esta pronto para ser publicado como uma landing page estatica.

Projeto:
- Pasta do site: website
- Build command: pnpm run build
- Pasta publicada: website/dist


Fluxo recomendado
-----------------
1. Criar um repositorio no GitHub para o projeto.
2. Enviar o codigo para esse repositorio.
3. No Netlify, clicar em "Add new site" > "Import an existing project".
4. Conectar com o GitHub.
5. Selecionar o repositorio.
6. Usar as configuracoes do arquivo netlify.toml.
7. Publicar.


Configuracao esperada no Netlify
--------------------------------
Base directory:
website

Build command:
pnpm run build

Publish directory:
website/dist


Antes de publicar
-----------------
Conferir:
- WhatsApp abrindo corretamente.
- Instagram abrindo corretamente.
- Textos no mobile.
- Depoimentos.
- Endereco.
- CRN.


Dominio
-------
Como o dominio ainda nao foi comprado, o site pode ficar inicialmente no dominio gratuito do Netlify, por exemplo:

bianca-zuim.netlify.app

Depois que o dominio definitivo for adquirido, basta configurar o dominio personalizado no Netlify e ajustar o DNS no provedor do dominio.

Sugestoes de dominio:
- biancazuim.com.br
- biancazuimnutri.com.br
- nutribiancazuim.com.br
